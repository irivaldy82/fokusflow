# FokusFlow Desktop

Aplikasi fokus anti-prokrastinasi lokal untuk Windows.

## Database SQLite

Versi desktop membuat database SQLite otomatis bernama fokusflow.db. Data
tetap di laptop dan tidak dikirim ke cloud. Gunakan tombol **Lokasi database**
untuk melihat folder database, atau **Cadangkan SQLite** untuk membuat salinan
file .sqlite di subfolder backups.

Untuk pindah laptop: buat backup .sqlite dari aplikasi lama, pindahkan file itu
ke laptop baru, lalu pilih **Pulihkan SQLite** pada halaman Pengaturan. Sebelum
memulihkan, aplikasi membuat salinan otomatis database lama sebagai pengaman.

## Unduh Windows

Buka tab **Actions**, pilih workflow yang berhasil, lalu unduh artefak
**FokusFlow-Windows-Installer**.
